- **[Cloudflare Function Demo](https://github.com/chadismoving/cf-functiondemo)** — A collection of demos showcasing Cloudflare capabilities.

- **[IP List Notification](https://github.com/chadismoving/iplist-notification)** — Automation built to solve an operational problem.
